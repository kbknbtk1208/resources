RooCode
Visual Studio Code (VS Code) の拡張機能として提供される AI コーディングアシスタント。開発者がコーディング作業を行うエディタ内で、大規模言語モデル (LLM) の能力を活用し、以下のようなタスクを支援してくれる。

- コード生成・補完: 自然言語による指示や既存コードの文脈に基づき、コードスニペットや関数、クラスなどを生成
- リファクタリング: コードの品質改善や可読性向上を目的としたリファクタリング案を提示し、適用
- コードレビュー・バグ検出: コード中の潜在的なバグや非効率な箇所、セキュリティリスクなどを指摘
- ドキュメント生成: コードに対応するコメントやドキュメンテーションを自動生成
- テストコード生成: 既存コードに対する単体テストや結合テストのコードを生成

VS Code 上で AI エージェントが動いて、コーディング等をしてくれる。→ 毎回チャットから出力された内容をコピペ等しなくても良くなる

MCP (Model Context Protocol) と MCP サーバーの概念
MCP (Model Context Protocol) は、AI モデル（特に LLM）が外部のツールやデータソース、API と対話するための標準化されたプロトコルです。AI が単にテキストを生成するだけでなく、能動的に情報を取得したり、外部システムを操作したりすることを可能にします。これにより、AI は開発環境やワークフローにより深く統合され、より高度なタスクを実行できるようになります。
MCP サーバーは、この MCP プロトコルを実装し、特定のツールやサービスへの具体的なインターフェースを提供するコンポーネント（サーバープロセス）です。RooCode のような MCP クライアント（AI）からのリクエストを受け取り、それを解釈して対象ツール（例: GitLab, Figma, Jira）を操作し、結果をクライアントに返します。

→AI エージェントが各種ツールと連携し、操作できるようになる

MCP サーバーは様々な方法で起動・接続可能:

パッケージ実行方式: npx などを用いて Node.js パッケージとして実行し、標準入出力 (Stdio) で接続する。
スクリプト実行方式 (Docker): Docker コンテナとして MCP サーバーを起動し、Stdio で接続する。
ネットワーク通信方式: MCP サーバーをデーモンプロセスとして起動しておき、HTTP (SSE など) 経由でネットワーク越しに接続する。

これにより、AI はローカルファイルシステムへのアクセス、コマンド実行、Web ブラウジング、各種 API 操作など、多彩な「アクション」を実行できるようになります。
