# プロジェクトに関する規約を提供する MCP サーバを作りたい

## 概要

複数人チームで開発するプロジェクトにおいて、コーディング規約やドメイン知識などをまとめた markdown ファイルを作成している。

コーディングエージェントで実装をする際、これらの情報のうち必要なものを必要なタイミングで提供する MCP サーバを作ることで、複数メンバーが統一感のある実装を行うことができるようにしたい。

## 想定ユーザーと使い方

npm パッケージとして private の gitlab に publish
プロジェクトメンバーが npx でコーディングエージェントと連携

## 受け入れ要件

- typescript で実装すること
- @modelcontextprotocol の sdk の最新版を使用すること
- サンプルの markdown として、react のコーディング規約と express のコーディング規約のファイルをそれぞれ作成し、MCP サーバーから提供できるようにすること
- npm package として publish する方法とこのリポジトリを local で起動する方法の 2 つで利用可能であること
  - **build の成果物に markdown ファイルを含める必要あり。build/index.js を実行することで、成果物の markdown ファイルを取得できるようにする必要がある**
- 以下のフローでコーディングエージェントと連携できるようにすること
  - コーディングエージェント(以降 A と呼称)：MCP サーバ(以降 M と呼称)から、提供可能な markdown のファイル名リストを取得
  - M:A に対し、/resource ディレクトリ配下の全ての markdown ファイルのファイル名をリスト化して返却
  - A:受け取ったファイル名の内、作業に関連しそうなファイル(ex:react_rule.md)を指定して M からリソース取得
  - M:A が指定した名前のファイルを提供
